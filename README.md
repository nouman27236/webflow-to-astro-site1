# Contemporary Dentistry — Astro Site

Rebuild of [the client's Webflow site](https://2019-00-contemporary-dentistry-1bcaa0.webflow.io/) in Astro + Tailwind CSS. Currently a single home page, deployed via Netlify.

See [CLAUDE.md](./CLAUDE.md) for project conventions and how to make changes.

## Commands

| Command           | Action                                      |
| :----------------- | :------------------------------------------ |
| `npm install`       | Install dependencies                        |
| `npm run dev`       | Start local dev server at `localhost:4321`  |
| `npm run build`     | Build production site to `./dist/`          |
| `npm run preview`   | Preview the production build locally        |
